# 方案：合并本地差异并统一插件来源

状态：已定稿

## 背景与目标

用户已授权本机安装双端插件，并进一步要求审查 6 个有差异的独立技能、合并有价值内容到仓库，最终只保留插件版本。

逐文件比较发现：app-icon-studio 和 write-ai-doc 主要缺少公开安装说明与许可证；task-artifacts 缺少运行时、编码及授权边界修正；两项 macOS 技能是仓库修正前版本；disk-cleanup 保留旧的只读定位经验，也含已被仓库替换的危险删除示例。完整本地差异另行归档，不提交缓存、个人路径或旧的危险默认行为。

## 方案与边界

- 保留仓库已有安全修正，将磁盘排查中可复用的只读定位内容补入参考文档。
- 插件升级到 0.1.1，两端仍使用一份仓库源码。宿主各自维护的缓存不手工合并或改写。
- 拟新增显式工具初始化器，在扫描目录之外创建稳定的插件根目录链接，并安装 task-artifacts 启动器。它不复制技能、不创建独立技能入口、不删除旧副本、不修改全局规则。
- 链接使用相对路径，启动器通过 HOME 解析入口。插件升级后需从新版缓存重新运行初始化器；不添加自动 hook。
- 本机升级成功后，显式初始化工具，并将两份全局规则中 write-ai-doc 和 task-artifacts 的旧路径改为稳定入口。只调整路径，不改变规则职责。
- 所有独立副本先以摘要核对并移到扫描目录之外的恢复备份，保留所有本地文件；清理相应安装记录，避免后续技能更新器重新安装重复项。
- 未识别的新修改、活跃文件或依赖不自动清理。其他技能、用户资料、现有任务记录和工具数据不在清理范围。

用户已明确要求合并并清理，本方案在已授权方向内直接实施，不重复请求确认。

## 验收

| 编号 | 标准 | 必要验证 |
| --- | --- | --- |
| AC-01 | 6 项差异有明确处理结论，没有回退仓库安全修正 | 差异报告与来源核对 |
| AC-02 | 初始化器不复制技能，保护无关命令和路径，支持重装、版本切换和迁移 | 隔离 HOME 回归测试与真实缓存初始化 |
| AC-03 | 双端插件 0.1.1 在推送前通过隔离安装，推送后可升级 | 原生 CLI、运行时技能清单与文件摘要 |
| AC-04 | 本机只通过插件发现这 11 项能力，旧副本可恢复 | 三个独立扫描目录及双端技能清单核对 |
| AC-05 | task-artifacts 命令和全局规则路径仍然有效 | 命令实测、稳定链接和旧引用检查 |
| AC-06 | 远端提交和本机插件文件与验证内容一致 | jj 推送、远端文件与本机缓存摘要核对 |

所有项均为必要条件。源码和隔离测试先完成，再上传、升级和清理；发布后的本机操作另行保留恢复清单与证据。

## 审核与记录

对初始化器、授权边界、相对链接、版本及安装说明执行独立 Standards 和 Spec 审核。结果账本与部署回执可在受审实现之外追加，不改变受审代码。已有分发规格见 [001-plugin-distribution](../001-plugin-distribution/000-plan.md)。

无。实际检测到新的本地修改或活跃使用时保留该项并报告，不扩大删除范围。
