## 六项差异处理

| 技能 | 本地差异 | 处理 |
| --- | --- | --- |
| app-icon-studio | 本地仍称未公开，缺少 MIT 声明；另有字节码缓存 | 保留仓库公开安装说明和许可证；功能文件已相同，不将缓存发布 |
| write-ai-doc | 缺少 README 与许可证声明 | 保留仓库版本，修复本机规则中的旧目录引用 |
| task-artifacts | 本地缺少平台、编码、授权与说明修正 | 保留仓库修正；增加插件根目录稳定入口及显式命令初始化，不再复制技能 |
| macos-direct-distribution | 本地保留早期系统版本下的命令限制说明 | 保留仓库按当前工具帮助核验的通用流程，不恢复版本假设 |
| macos-finder-extension | 本地为未包含签名失败守卫和通用图标参考的旧版本 | 保留仓库诊断修复与授权边界，不恢复不经实测的元数据改写指令 |
| disk-cleanup | 旧工具路径定位、固定容量估计、批量删除示例 | 补回可复用的只读工具位置和 DerivedData 归属读取方法；不恢复批量删除或全局终止进程 |

差异属于发布前版本与仓库改进之间的差异，没有发现尚未上传的独立新功能。所有旧文件在实际退役时均保留恢复备份；没有将有差异的文件直接永久删除。

## 版本与部署边界

插件版本为 0.1.1。部署前实现审核固定 11 个仓库文件，另绑定本机迁移脚本及完整包前置检查的内容摘要。此结果账本是随后增加的验收记录，不改变受审实现。
