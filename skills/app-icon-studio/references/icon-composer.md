# Icon Composer 素材规范

## 选择交付深度

“方便放进 Icon Composer”默认仍是无圆角的正方形源图。不要据此自动扩展为分层工程。明确要求可编辑前景或分层时，才准备独立图层。

一张完整 PNG 可以作为视觉参考或单一栅格素材，但不能声称背景、主体和材质已独立可编辑。需要真正分层时交付背景配置、独立主体及必要装饰，并保留整体预览。

## 分层方法

先根据选定图稿定义最少的语义图层。所有图层使用同一 1024 × 1024 坐标系，保持位置和比例。不要分别紧裁剪后再随意居中。

简单颜色或渐变背景记录色号和方向，留给 Icon Composer 设置。复杂背景可以作为独立图片。前景使用 `foreground` 模式生成透明 PNG；参考原图并保持构图。不要通过复制同一整图来伪造多层。

已有简洁矢量源时保留 SVG。需要几何描绘时只使用干净路径，不把 PNG 包装进 SVG 冒充矢量。复杂材质保留 PNG，并说明栅格限制。

为动态材质准备的前景保持基础形状，把投影、折射和高光交给 Icon Composer。用户明确要求保留固定玩具材质时可以保留栅格效果，但要说明这些光影无法分开编辑。

## 原生导入

只在用户要求 `.icon` 工程或实际导入时检测本机应用和可用适配器。通过已验证的界面或适配器保存，再重新打开工程检查图层与外观。

本 Skill 不提供原生包序列化器。不要猜测 `icon.json` 字段、复制其他工程的私有结构，或把文件夹改后缀当成完成。没有可用应用或适配器时交付已检查的素材与图层顺序，明确原生工程尚未生成。

按实际应用版本检查可用外观。没有打开应用时，不声称完成 Icon Composer 导入、外观渲染或 Xcode 集成。
