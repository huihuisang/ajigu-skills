# 开发机磁盘清理

排查 macOS 开发环境的磁盘占用，给出可核实的清理清单，并在用户授权范围内释放空间。输出处理路径、跳过原因和同一文件系统前后的可用空间，避免把目录大小当作实际回收量。

## 安装

把仓库地址交给 Agent：“请从 https://github.com/huihuisang/ajigu-skills 安装 disk-cleanup。”

```bash
npx skills add huihuisang/ajigu-skills -g -y --skill disk-cleanup
```

技能目录名和调用名均为 disk-cleanup。也可以将完整目录复制到宿主的技能目录；命令安装需要 Node.js 与网络，实际排查不需要 Node.js。

## 配置与依赖

无需额外配置或密钥。支持 macOS 终端；使用系统的 df、du 和进程检查工具。Xcode、Homebrew、Android 和 Gradle 仅在已安装对应环境时检查。Windows 与 Linux 清理不在范围内。

## 使用

请求：“看看开发目录为什么占了这么多空间，先给我具体清单。”

如果用户进一步授权删除，技能重新核对清单与活跃进程，再处理已授权内容。不会把项目中的 build、dist 或 artifacts 统一视为垃圾。

## 数据与权限边界

排查保持本地，不自带上传服务。宿主可能处理终端输出，请按宿主的数据策略使用。清理可以删除文件、重下载依赖或丢失模拟器数据；安装本技能不授权这些操作。保留源码、原始素材、发布文件、密钥、签名配置和必须留存的证据。

## 验证与排查

本技能没有自动删除脚本。发布检查覆盖文档结构、资源链接及危险命令筛查，不执行真实清理。实际任务应以同一磁盘的 df 前后结果为准；权限不足、APFS 共享块和并发写入均需注明。
