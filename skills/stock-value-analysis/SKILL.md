# Stock Value Analysis

目标不是预测短期股价，而是用有限上下文回答四件事：

1. 企业怎样赚钱，竞争优势是否真实；
2. 最新经营状态与利润质量如何；
3. 当前价格隐含怎样的未来，长期收益是否有安全边际；
4. 哪些新证据会推翻当前判断。

核心顺序：

> 多年数据看轮廓 → 最新财报找变化 → 围绕异常回溯历史 → 正常化盈利 → 估值与证伪。

不要一开始顺序阅读全文多年份财报。广度用结构化数据取得，深度只给真正影响投资判断的问题。

## 分析边界

- 默认联网获取截至分析日的最新公开信息，并注明数据截止时间。
- 优先长期基本面，不做技术形态、次日涨跌或无依据目标价预测。
- 结论必须区分事实、管理层解释、分析推断和不确定性。
- 这是研究辅助，不是个性化投资建议；不要替用户决定仓位或承诺收益。
- 任何外部写入、交易或账户操作都不属于本 Skill。

## 按需读取 References

保持主上下文轻量，只在进入对应阶段时读取：

- 发现财务异常、需要评价企业质量或完成全面分析时，读取 [references/financial-diagnostics.md](references/financial-diagnostics.md)。
- 需要判断价格、计算回报、评分或生成最终报告时，读取 [references/valuation-and-output.md](references/valuation-and-output.md)。

不要在研究开始时同时加载所有参考文件。

## 一、确认研究对象

先确认：

- 公司全称、股票代码、上市地与报告币种；
- 当前股价、市值、净现金或净负债；
- 最新完整财年、最新中期或季度报告；
- 是否存在同名公司、不同股份类别或重大停牌重组。

用户只输入一个明确公司或代码时，默认执行完整但渐进的分析；若身份有歧义，先澄清再查资料。

## 二、第一层：多年结构化筛查

先获取 5～10 年核心指标的结构化序列，不逐份阅读全文。优先使用交易所、公司数据表和可信金融数据库，并对关键数字回到正式披露抽查。

最小序列：

| 维度 | 指标 |
| --- | --- |
| 规模 | 营收、归母及扣非利润 |
| 盈利 | 毛利率、营业利润率、净利率、ROE、ROIC |
| 现金 | 经营现金流、自由现金流、资本开支 |
| 营运 | 应收、存货、合同负债及相关周转天数 |
| 资产负债 | 现金、有息负债、商誉、净负债率 |
| 股东回报 | 分红、回购、总股本、股权激励稀释 |

根据行业替换或增加真正有解释力的指标，例如银行的净息差和不良率、SaaS 的留存率、半导体的库存与研发费用率。

这一层只输出紧凑表格和趋势标签，用于回答：

- 长期增长是否真实；
- 利润是否转化为现金；
- 资本回报率是否可持续；
- 杠杆、稀释和营运资金是否逐步恶化；
- 最新一期是否偏离长期基线。

不要为了填满表格而收集不影响判断的数据。

## 三、第二层：精读最新正式披露

最少精读：

1. 最新年报；
2. 最新季度或半年报；
3. 最新业绩说明会、业绩预告或投资者关系记录（如有）。

年报用于理解审计意见、附注、分部、会计政策、资本配置和完整现金流；最新中期报告用于捕捉年报后的变化。不能只读最新季度摘要，也不能因为已有十年数据库就跳过原始披露。

重点提取：

- 本期变化及管理层解释；
- 分部、产品、地区或客户结构变化；
- 现金流与利润的差异；
- 应收、库存、减值、负债、商誉和资本开支；
- 会计政策、审计意见、关联交易和重大承诺；
- 管理层对未来的可核验表述。

使用目录、关键词和财务附注定位相关页面，不把整份报告文本复制进主上下文。

## 四、建立异常登记表

把最新披露与多年基线比较，只保留可能改变企业质量、正常化利润或估值的异常。

| 异常 | 最新证据 | 长期基线 | 可能解释 | 重要性 | 待验证问题 |
| --- | --- | --- | --- | --- | --- |

优先检查：

- 营收、利润与经营现金流背离；
- 应收或库存显著快于收入；
- 毛利率、费用率、ROIC 或自由现金流持续变化；
- 债务、商誉、资本开支或股本突然上升；
- 大额并购、减值、补贴、投资收益或一次性项目；
- 分部、客户集中度、会计口径、审计意见或关联交易变化；
- 管理层解释与数据不一致。

“偏离历史”只是调查触发器，不等于风险结论。根据对估值和投资逻辑的影响排序，通常只深入最重要的 2～4 个问题。

## 五、第三层：异常驱动的历史回溯

只有异常登记表形成后，才回溯往年原始财报。

回溯规则：

- 先看同季节、相邻年度和异常首次出现的年份；
- 通常回溯 3～5 年；周期、并购、会计政策或慢性恶化问题才扩展到 8～10 年；
- 只读取能回答问题的附注、表格和管理层说明；
- 同一数字至少核对单位、期间、合并范围和是否重述；
- 证据已经解释异常，或继续查找不会显著改变结论时停止；
- 找不到足够证据就标记“未知/待验证”，不要用资料数量制造确定感。

最终将异常分类为：

- 🟢 **已基本解释**：历史规律、商业模式和后续数据相互支持；
- 🟡 **需要跟踪**：解释合理但尚未被后续结果验证；
- 🔴 **实质恶化**：多个独立证据显示经营或财务质量下降。

## 六、子 Agent 委派协议

当运行环境允许协作且异常问题相互独立时，可以并行委派。若环境不支持子 Agent，则按同样协议顺序执行。

### 委派原则

- 按“问题”委派，不按“年份”委派。
- 不要让多个 Agent 阅读同一批完整财报。
- 每个 Agent 只调查一个可证伪问题，通常同时进行 2～4 项。
- 子 Agent 只做只读研究，不获得交易、发消息或修改外部系统的权限。
- 主 Agent 保留公司身份、最新财报、异常登记表和最终估值，避免重复上下文。

好的任务示例：

> 调查该公司 2021–2025 年应收账款是否实质恶化。核对应收增速、周转天数、账龄、坏账准备、主要客户账期和年末回款；优先正式财报。只返回能够支持或反驳“通过延长账期换取收入”的证据。

不好的任务示例：

> 阅读 2021 年全部财报并总结。

### 子 Agent 任务书必须包含

- 公司、代码、市场和报告币种；
- 唯一研究问题与待检验假设；
- 允许查看的期间和优先来源；
- 需要返回的具体指标；
- 输出上限与停止条件。

### 统一证据包

每个子 Agent 最多返回：

1. **结论**：一到两句话；
2. **证据表**：最多 8 行，包含期间、指标/事实、数值、原始来源；
3. **支持证据**与**反证**：各不超过 3 点；
4. **管理层解释核验**：数据是否支持；
5. **风险等级**：🟢 / 🟡 / 🔴；
6. **置信度与缺口**；
7. **来源链接**。

禁止回传完整财报、长段摘录、无筛选搜索结果或与研究问题无关的公司介绍。主 Agent 只把证据包中会改变判断的内容合并进正文。

## 七、企业质量与正常化盈利

异常调查后再评价：

- 商业模式与客户价值；
- 护城河和竞争反应；
- 管理层诚信及资本配置；
- 增长来源、资本需求和可预测性；
- 利润质量、资产负债表和周期位置。

不要先评分再找理由。需要完整诊断标准时读取 `financial-diagnostics.md`。

估值前必须确定正常化盈利，剔除或调整：

- 资产出售、补贴和异常投资收益；
- 一次性减值、税率和重组费用；
- 极端周期高点或低点；
- 不可持续的低研发、低营销或低资本开支；
- 并购造成的口径变化和股份稀释。

## 八、估值与反向验证

只有企业质量、异常调查和正常化盈利完成后才估值。

默认包含：

- Bear / Base / Bull 三情景；
- 未来 5 年合理市值或每股价值；
- 10%、12%、15% 目标年化收益率对应买入价格；
- 当前价格反向隐含的增长率；
- 安全边际与 3～5 条投资逻辑证伪条件。

禁止同时使用高增长率和高退出估值形成“双重乐观”。详细公式、评分、价格区间和报告格式见 `valuation-and-output.md`。

## 九、来源和证据优先级

1. 公司正式披露；
2. 交易所或法定披露平台；
3. 公司 Investor Relations；
4. 权威金融数据库；
5. 券商研报和财经媒体。

二手来源可以帮助理解行业和市场预期，但不能替代关键财务事实。数字冲突时优先原始财报，并说明口径差异。

所有可能变化的数据都标明日期并提供链接。短引用只用于关键措辞，其余内容用自己的话概括。

## 十、最终输出

完整报告至少包括：

1. 一句话结论：公司质量、当前估值、最大机会、最大风险；
2. 商业模式与竞争优势；
3. 多年结构化趋势表；
4. 最新财报及异常登记表；
5. 针对异常的历史验证与风险等级；
6. 利润质量、管理层、成长与可预测性；
7. 三情景估值、反向估值和价格区间；
8. 投资逻辑证伪条件；
9. 关键数据来源与截止日期。

先讲结论，再解释证据。重要指标必须用普通语言说明“是什么、为什么重要、最坏意味着什么、证据是否支持”。

如果用户要求简版，只压缩表达，不跳过异常验证和估值假设。若生成投资结论图，它只能总结已经完成的文字分析，不能替代证据与解释。

## 完成标准

只有满足以下条件才结束：

- 多年趋势来自紧凑结构化数据，而不是大量原文堆叠；
- 最新年报和最新中期披露都已核验；
- 重要异常完成解释、反证和风险分级；
- 子 Agent（如使用）按问题返回有限证据包；
- 估值基于正常化盈利并展示关键假设；
- 结论包含不确定性和可观测的证伪条件。
