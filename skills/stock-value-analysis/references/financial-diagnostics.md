# Financial Diagnostics

仅在全面评价企业质量或异常登记表需要深入调查时读取本文件。

## 1. 先理解生意

用普通语言回答：

- 公司卖什么，怎样收费，毛利来自哪里；
- 客户是消费者、企业、政府、经销商、OEM 还是平台参与者；
- 客户为什么选择它，切换成本是什么；
- 供应商、客户和渠道谁拥有议价权；
- 收入是一次性、订阅、交易抽成、项目制还是资源价格驱动；
- 增长需要多少库存、固定资产、研发、销售费用和营运资金。

判断行业类型：周期、消费、平台、SaaS、金融、医药、半导体、资源、公用事业、重资产制造或其他。不同类型不能套同一阈值。

## 2. 财务时间线

多年结构化筛查通常覆盖：

| 指标 | 观察目的 |
| --- | --- |
| 营收及增速 | 规模与周期 |
| 归母、扣非与营业利润 | 核心盈利和一次性项目 |
| 毛利率、营业利润率、净利率 | 定价权、产品结构和费用纪律 |
| ROE、ROIC | 资本效率 |
| 经营现金流、自由现金流 | 利润含金量 |
| 应收、存货、合同资产/负债 | 营运资金和收入质量 |
| 现金、有息负债、净负债率 | 偿债与抗风险能力 |
| 商誉、并购、减值 | 资本配置风险 |
| 资本开支、研发投入 | 维持与增长所需投入 |
| 分红、回购、总股本 | 股东实际回报和稀释 |

比较数据前核对币种、单位、财年、合并范围、会计准则和是否重述。

## 3. 利润与现金

核心链条：

> 利润 → 经营现金流 → 自由现金流 → 股东可获得现金。

辅助指标：

`Cash Conversion Ratio = Operating Cash Flow / Net Profit`

不要机械按单季比率下结论。税费、预付款、回款周期、备货和季节性都可能造成短期差异。

需要追问：

- 经营现金流长期是否跟上利润；
- 自由现金流弱是增长投入还是维持性资本开支；
- 现金是否被受限、质押或留在不可自由调配的主体；
- 利润是否主要来自补贴、投资收益、公允价值或资产处置；
- 股权激励是否被忽略却持续稀释股东。

## 4. 应收账款

当应收增速长期高于收入，调查：

1. 应收周转率和回款天数；
2. 账龄结构及一年以上余额；
3. 坏账准备、信用减值和实际核销；
4. 正常客户账期是否延长；
5. 客户集中度和关联方应收；
6. 同季历史与年末回款情况；
7. 收入确认政策及合同资产变化。

`Receivable Turnover = Revenue / Average Receivables`

`Days Sales Outstanding ≈ Period Days / Receivable Turnover`

从 50 天变为 55 天和从 50 天持续升至 130 天不是同一级别风险。结合行业、季节和坏账证据判断。

## 5. 存货

当存货快于收入时，区分：

- 主动备货、旺季、新产品或供应链安全库存；
- 在产品增加与产能爬坡；
- 产成品滞销、渠道压货或需求转弱；
- 原材料价格变化；
- 并购和合并范围变化。

核对原材料、在产品、产成品、委托加工和合同履约成本，并检查：

- 周转天数；
- 库龄；
- 跌价准备及计提政策；
- 后续销售、毛利率和库存消化；
- 半导体、消费电子等快速迭代行业的老产品风险。

## 6. 利润率和资本回报

利润率变化可能来自价格、销量、产品组合、原材料、产能利用率、汇率、渠道补贴或会计口径。

ROIC 下降需要拆解：

- 营业利润率是否下降；
- 营运资金是否占用更多资本；
- 固定资产和并购资产是否尚未产生回报；
- 商誉和资本化项目是否掩盖真实投入；
- 企业是否为了增长接受越来越低的增量回报。

高 ROE 若主要来自高杠杆，不等于高质量。

## 7. 负债、资本开支和偿债

关注：

- 短债与可用现金、利息覆盖；
- 浮动利率、货币错配、担保和或有负债；
- 债务到期分布；
- 资本开支是维持性还是增长性；
- 租赁负债、供应链融资和表外承诺；
- 分红回购是否依赖举债。

周期企业在高景气时的低杠杆不代表低谷安全，使用中周期现金流压力测试。

## 8. 管理层和资本配置

比较“过去说过什么”与“后来发生了什么”：

- 指引与实际结果；
- 并购承诺与商誉减值；
- 回购价格和实际注销；
- 融资、股权激励与每股价值；
- 关联交易、大股东资金占用和减持；
- 研发、营销和资本开支是否服务长期竞争力；
- 失败项目是否及时止损并透明披露。

管理层解释只能作为待检验假设。库存为扩张而增加，就检查后续收入、库存消化、毛利率和减值；应收因季节性上升，就检查同季历史和年末现金回收。

## 9. 护城河、增长和可预测性

护城河可能来自品牌、网络效应、转换成本、成本、规模、技术、专利、数据、渠道、生态、牌照或稀缺资源。

必须回答：

> 资金充足的竞争对手为什么仍难以抢走客户和利润？

增长拆解：

`Revenue Growth ≈ Volume + Price + New Products + New Markets + Share Gain`

同时判断：

- 总市场与渗透空间；
- 增长是否牺牲利润率、现金流或资本回报；
- 新增长是否依赖单一客户、政策、商品价格或融资；
- 未来五年利润能否相对可靠地估计。

可预测性越低，估值假设越保守，安全边际越大。

## 10. 行业指标示例

- 银行：净息差、不良率、关注类贷款、拨备覆盖率、核心一级资本；
- 保险：综合成本率、新业务价值、偿付能力、投资收益；
- SaaS：ARR、净收入留存率、流失率、获客成本、剩余履约义务；
- 半导体：库存、产能利用率、研发费用率、产品结构和减值；
- 公用事业：利用小时、监管回报、燃料成本、资本开支和负债；
- 资源：储量、产量、现金成本、维持性资本开支和周期中枢价格；
- 医药：专利期限、管线阶段、研发成功率、单品依赖和商业化效率。

只选择能解释该公司价值驱动因素的指标。

## 11. 异常定性

所有重要异常遵循：

> 发现 → 提出竞争性解释 → 查找支持与反证 → 用历史或后续数据验证 → 定性。

### 🟢 已基本解释

- 同季或周期规律一致；
- 周转率、账龄、减值等没有同步恶化；
- 后续数据恢复；
- 管理层解释与数据一致。

### 🟡 需要跟踪

- 解释有合理机制，但缺少后续验证；
- 指标只恶化一期或证据相互冲突；
- 若下一期不恢复，可能影响正常化盈利。

### 🔴 实质恶化

- 多期周转、现金流、利润率或资本回报恶化；
- 账龄、坏账、减值和负债出现相互支持的证据；
- 管理层解释与后续事实冲突；
- 异常改变商业模式、资产负债表安全或每股价值。

## 12. 投资逻辑证伪

每家公司给出 3～5 条可观测条件，优先量化但不要使用缺乏行业依据的任意阈值。

常见类型：

- 核心产品份额或客户留存持续下降；
- 毛利率或 ROIC 跌破商业模式可接受水平；
- 应收、库存或自由现金流连续多期恶化；
- 杠杆超过中周期现金流可承受范围；
- 管理层持续进行低回报并购或大规模稀释；
- 技术、监管或渠道变化破坏原护城河。

证伪条件必须与正文投资逻辑一一对应。
