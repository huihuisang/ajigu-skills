# Valuation and Output

仅在企业质量、异常调查和正常化盈利已经完成后读取本文件。

## 1. 正常化盈利

不要直接使用最近一年最高利润。调整：

- 一次性资产出售、补贴、投资收益和公允价值变化；
- 异常税率、减值、诉讼和重组费用；
- 极端周期利润；
- 并购导致的口径变化；
- 不可持续的低研发、低营销或低维持性资本开支；
- 股权激励和股份稀释。

周期企业优先使用中周期利润或多年平均；稳定企业可以从最新盈利出发，但要说明为什么具有代表性。

## 2. 五年简化估值

默认持有期 `N = 5` 年。

`Future Profit = Normalized Profit × (1 + g)^N`

`Future Fair Market Cap = Future Profit × Exit PE`

目标收益率为 `r` 时：

`Target Purchase Market Cap = (Future Fair Market Cap + Cumulative Dividends) / (1 + r)^N`

每股口径：

`Target Buy Price = (Future Fair Price + Cumulative DPS) / (1 + r)^N`

分别反推 10%、12%、15% 年化收益要求对应的当前价格或市值。

退出估值要结合行业成熟度、增长、可预测性、资本回报、利率和长期估值区间，不要机械沿用当前 PE。

## 3. 禁止双重乐观

不能同时使用高利润增长和高退出估值。公司成熟时，增长率与合理估值通常一起下降。

对每个情景检查：

- 收入增长是否超过可解释的市场空间；
- 利润增长是否无依据地长期快于收入；
- 利润率是否超过行业和公司历史合理上限；
- Exit PE 是否与第五年增长和资本回报匹配；
- 股份稀释、净债务和分红是否被正确计入。

## 4. 三情景模型

| Scenario | Profit CAGR | Year 5 Profit | Exit Multiple | Dividends | Year 5 Equity Value | 5Y IRR |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Bear | | | | | | |
| Base | | | | | | |
| Bull | | | | | | |

### Bear

体现需求、利润率、资本开支或竞争不利，但不必假设公司必然失败。

### Base

使用当前证据支持度最高、可重复计算的假设，是最终判断核心。

### Bull

体现执行良好和优势扩大，但不能依赖没有证据的新业务奇迹。

清楚列出增长、利润率、净现金/净负债、股份数和退出估值假设。

## 5. 反向估值

从当前企业价值或市值反推：

- 在目标回报率和合理 Exit PE 下，第五年需要多少利润；
- 对应利润 CAGR；
- 这一增长是否与市场空间、资本需求和竞争现实一致。

反向估值用于回答：

> 当前价格已经提前计入多少成功？

如果隐含假设明显高于 Base Case，价格昂贵；若低于保守可实现水平，才可能存在安全边际。

## 6. 安全边际和价格区间

安全边际取决于企业质量、预测难度、杠杆、周期、技术变化和治理，不固定套用 30%。

根据 Base Case 与目标收益率划分：

- 🟢🟢 **Very Attractive**：悲观假设下仍有明显缓冲；
- 🟢 **Attractive**：Base Case 长期回报较高；
- 🟡 **Fair Value**：价格大致反映合理未来；
- 🟠 **Expensive**：需要偏乐观执行；
- 🔴 **Very Expensive**：依赖高增长和高估值同时成立。

所有区间都注明对应盈利、增长和退出估值假设。基本面变化时重新计算。

## 8. 完整报告结构

### 1. 一句话结论

回答公司质量、当前估值、最大机会和最大风险。

### 2. 公司怎样赚钱

用普通语言解释产品、客户、收费方式和价值链位置。

### 3. 竞争优势

说明客户为什么选它，以及竞争者为何难以夺走利润。

### 4. 多年趋势

只展示关键结构化指标和方向，不堆叠多年原文。

### 5. 最新财报

说明增长、利润率、现金流、资产负债和分部变化。

### 6. 异常调查

展示异常登记表、针对性历史证据和 🟢 / 🟡 / 🔴 结论。

### 7. 企业质量

评价利润含金量、管理层、成长、护城河和可预测性。

### 8. 三情景估值

展示假设、第五年价值与 IRR。

### 9. 当前价格隐含什么

展示反向估值和现实性判断。

### 10. 价格区间

给出不同目标收益率下的区间和依赖假设。

### 11. 证伪条件

给出 3～5 条未来可跟踪条件。

### 12. 评分与来源

列出总分、主要扣分项、数据截止日期和关键原始来源。

## 9. 通俗解释规则

任何影响判断的指标都按以下顺序解释：

1. 它是什么；
2. 为什么重要；
3. 异常可能有哪些竞争性解释；
4. 最坏可能意味着什么；
5. 当前证据支持哪种解释；
6. 下一期观察什么。

例如，不只写“应收 +35%”，而要说明它代表已确认收入但尚未收到的现金，并用周转率、账龄、坏账和后续回款判断风险。

完整文字分析结束后，仅在用户要求视觉总结，或当前工作流明确包含图片交付时生成。

设计方向：

- editorial investment memo；
- premium research note；
- 现代、克制、手机友好；
- 英文 UI 标签，中文解释文本保持清晰；
- 大量留白，不做密集 dashboard；
- 不使用“抄底、暴涨、梭哈、稳赚”等宣传词。

图片只保留：

- 公司、代码、价格和日期；
- 一句话结论与总分；
- 4～6 个关键指标；
- 2～3 个主要风险；
- Bear / Base / Bull；
- 价格区间与核心证伪条件。

正文负责解释，图片负责五秒内总结；图片不能引入正文没有的新结论。
