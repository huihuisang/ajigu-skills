# 项目规格与决策记录

为项目保留可追溯的设计理由、验收标准与实施证据。交付 docs-ai 中的简短方案和结果记录，避免决策只存在于聊天中。默认使用中文，用户可指定其他语言。

## 安装

把仓库地址交给 Agent：“请从 https://github.com/huihuisang/ajigu-skills 安装 write-ai-doc。”

```bash
npx skills add huihuisang/ajigu-skills -g -y --skill write-ai-doc
```

也可以将完整目录复制到宿主的全局技能目录，重新加载技能列表。命令安装需要 Node.js 与网络，它们不是技能运行依赖。

## 配置与依赖

无需额外配置或密钥。运行时只需要具备文件读写能力的 Agent；不依赖特定操作系统。命令与链接示例已做静态核对，未逐一测试所有宿主。

## 使用

请求：“为这个改动写一份包含验收标准的项目方案，再按实际验证结果记录实施情况。”

新主题输出 `docs-ai/NNN-short-slug/000-plan.md` 和实施后的 `001-action.md`；已有主题沿用同一记录。验收编号贯穿方案与结果，实施、验证和审核状态分别记录。

## 数据与权限边界

内容保存在用户选择的项目中；技能不自带网络客户端，不上传项目内容。宿主自身如何处理输入取决于其配置。写文档不授权改代码、发布或创建提交；普通调查和小修默认无需建记录。

## 验证与排查

检查资源链接、编号冲突，以及文档中的路径和证据是否真实存在。无法执行的验证应标为未验证。模板见 [方案模板](references/plan-template.md) 和 [结果模板](references/action-template.md)，无需安装测试运行时。
